# Sales Analytics Dashboard

A modern, responsive, client-side Sales Analytics Dashboard built with vanilla HTML, CSS, and JavaScript.

## Features

- **No Frameworks or Build Tools**: Pure vanilla HTML5, CSS3, and modern JavaScript.
- **Strictly No CSS Variables**: Explicit color literals and clean typography for universal compatibility.
- **Zero Backend Required**: Runs entirely client-side.
- **Persistent Data**: Uses WebStorage (`localStorage`) for real-time persistence with automatic seed dataset.
- **Interactive Visualizations**:
  - Revenue & Net Profit Timeline (with Daily/Monthly interval toggles)
  - Sales by Product Category (Donut chart with segment percentages)
  - Sales by Channel (Bar chart)
  - Regional Sales Distribution (Horizontal bar chart)
- **Comprehensive KPI Cards**:
  - Gross Revenue & Growth %
  - Net Profit & Profit Margin %
  - Total Orders & Completed Transactions count
  - Average Order Value (AOV)
  - Fulfillment & Success Rate %
- **Sales Quota & Target Progress Tracker**: Visual progress towards monthly revenue milestones.
- **Transactional Ledger (CRUD)**:
  - Add, edit, and delete transactions with instant calculation
  - Instant live search by customer, email, product, or order ID
  - Filter by transaction status (Completed, Pending, Refunded)
  - Multi-criteria sorting and pagination
- **Data Export & Reset**:
  - One-click export to CSV
  - Reset to realistic sample dataset

## Quick Start

Simply open `index.html` in any modern web browser or host it with any static web server (such as GitHub Pages).
